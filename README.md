# WhatsApp Management System

A robust console-based management system developed in C++ to simulate and manage WhatsApp-like messaging features, contact lists, and chat logs efficiently.

## 🚀 Project Overview
This project is built using Object-Oriented Programming (OOP) principles in C++. It features a modular structure that allows for managing contacts, sending messages, and organizing chat history, demonstrating strong command over data structures and system design.

## 🛠 Tech Stack
- **Language:** C++
- **Key Concepts:** OOP (Classes, Inheritance, Polymorphism), File Handling, Data Structures.
